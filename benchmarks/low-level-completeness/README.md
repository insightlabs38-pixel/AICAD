# benchmarks/low-level-completeness

Corpus of advanced geometry tasks (spline-defined retaining hook,
variable-section sweep, twisted loft, custom impeller blade, lattice cell,
cam profile, nonstandard gear tooth, manually trimmed manifold, open-shell
repair) used to show the low-level DSL is general enough that the compiler
does not need feature proliferation. Any solution requiring a new compiler
intrinsic must be classified and justified.

Plan references: `docs/plan/16_TESTING_BENCHMARKS_ACCEPTANCE.md` §6.
