# AICAD development planning

`project/planning/` contains **internal development planning**, not end-user or contributor reference documentation.

## Active structure

- `transitions/` — bounded stage-transition/reconciliation records.
- `roadmap/` — future-roadmap audits and planning artifacts that are not normative unless separately accepted through the normal owner/RFC/spec process.

Current user documentation lives under `docs/user/`. Current contributor/developer documentation lives under `docs/developer/`.

## Historical foundation plan

The original frozen planning bundle remains at `docs/plan/` during this transition because Stage-0..3 reports, task records, source comments, and RFC-era evidence reference those paths extensively. It is **internal historical/foundation planning**, despite the legacy location under `docs/`; it is not part of normal user/developer documentation navigation. Physical relocation is deferred to a later path-maintenance/spec-cleanup pass if the benefit justifies the repository-wide reference churn.
