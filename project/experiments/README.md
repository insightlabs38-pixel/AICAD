# Architecture-alternative experiments

Scratch space for prototyping unresolved architecture alternatives listed in
`project/OWNER_DECISIONS.md` (e.g. D8 OCAF vs. kernel-independent semantic
graph, D15 WASM vs. external-process plugin runtime) before the owner rules
on them.

Per `AICAD_AGENT_OPERATING_MODEL.md` §7: "The agent can prototype
alternatives and collect evidence, but the owner chooses." Prototypes here
are disposable evidence, not committed architecture — do not wire an
experiment into the real crates/ tree until the corresponding decision is
recorded in `project/DECISION_LOG.md`.
