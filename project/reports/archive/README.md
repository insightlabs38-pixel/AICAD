# Archived implementation evidence

Completed Stage-0..3 implementation reports are preserved here to keep routine agent context focused on active work.

- `stage0/` — orientation and AICAD-001..014 evidence.
- `stage1/` — AICAD-015..037 evidence and Stage-1 independent review.
- `stage2/` — AICAD-038..064 evidence, including Stage-2 subtask reports.
- `stage3/` — AICAD-064A..079B evidence, including the final incremental-remediation report.

The original report contents are preserved as the same Git blobs where possible. Compatibility pointer files remain at former `project/reports/<name>` paths so frozen task metadata and historical links do not become dead. Those pointers are navigation only; the archive copy is the historical evidence.

Archiving means moving evidence out of routine context, not deleting it.
