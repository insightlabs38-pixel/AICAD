# Archived stage-gate evidence

Completed Stage-0..3 gate evidence is preserved here so the active `project/gates/` surface can focus on the current transition and Stage-4 traceability.

- `stage0/` — Stage-0 owner gate.
- `stage1/` — Stage-1 batch checkpoints and owner gate.
- `stage2/` — Stage-2 batch checkpoints and owner gate.
- `stage3/` — Stage-3 batch checkpoints and final gate snapshot.

The Stage-0→4 traceability matrix remains at `project/gates/stage-0-4-traceability-matrix.md` because it still covers Stage 4. During this transition the final Stage-3 gate also remains easy to locate at `project/gates/stage-3-gate.md`; its historical snapshot is additionally preserved under `archive/stage3/`.

Compatibility pointer files at former completed-gate paths keep frozen links navigable. Archiving does not confer owner approval and does not rewrite historical recommendations.
