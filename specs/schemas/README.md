# specs/schemas

This directory contains machine-readable schemas that actually exist in the current repository.

## Current canonical schema

- `diagnostic.schema.json` — current structured diagnostic schema, governed by D10 / `project/DECISION_LOG.md#DL-18`.

## Planned/reserved schemas

The foundation plan and future roadmap discuss build, package, skill, artifact, verification/evidence, and other machine-readable schemas. Files such as `build.schema.json`, `package.schema.json`, `skill.schema.json`, or `artifact.schema.json` are **not** current canonical artifacts until the repository actually creates and approves them. Their mention in planning material is not a claim that they exist or that their final compatibility contract has been frozen.

Plan references remain useful background: `docs/plan/22_REPOSITORY_WORK_PACKAGES.md` §1 and `docs/plan/17_CLI_DIAGNOSTICS_SCHEMA.md` §11, §13-14. Current implementation/specification takes precedence over illustrative future schema inventories.
