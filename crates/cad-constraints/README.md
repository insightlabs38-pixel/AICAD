# cad-constraints

WP-08 (Constraint system). Constraint IR, sketch solver adapter, assembly
solver adapter, equation constraints, DOF/conflict reporting, solver
tolerance policy. Architecture rule: solvers are replaceable; source-level
constraint semantics are not solver-specific. Exact IR semantics and the
solver-independence boundary are an open owner decision — see
`project/OWNER_DECISIONS.md` D11.

Plan references: `docs/plan/08_CONSTRAINTS_REQUIREMENTS_TESTS.md` §2-6;
`docs/plan/22_REPOSITORY_WORK_PACKAGES.md` WP-08.
