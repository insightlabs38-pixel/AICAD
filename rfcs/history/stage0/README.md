# Stage-0 RFC snapshot

This directory preserves the exact Stage-0-era RFC bodies that were present at the start of the Stage-3 -> Stage-4 normative cleanup (`8d9ba734896f05220028dd5414c723c9ba8a484f`). The files are retained with their original Git blobs so historical rationale, alternatives, and then-open questions remain available verbatim.

The same RFC numbers at `rfcs/0001-...` through `rfcs/0005-...` are the **current reconciled normative versions**. Those current files incorporate later owner decisions and current implementation boundaries. When an old snapshot says D5/D10/D11/D20 is open, that statement is historical; the live `project/OWNER_DECISIONS.md` / `project/DECISION_LOG.md` controls current status.

Do not use this snapshot as current source-language/API documentation. It exists for design archaeology and rationale preservation.
