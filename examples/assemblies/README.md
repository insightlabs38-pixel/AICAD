actuator, robot arm, nested assembly with repeated fasteners, vendor STEP
parts, configuration replacement).

paper/spec example from AICAD-012, proving RFC-0001 through RFC-0005 can

semantic contradiction (`project/reports/AICAD-012.md`,
`project/reports/AICAD-013.md`). It is illustrative, not compilable —
