# AICAD user documentation

This documentation describes the **implemented Stage-3 product surface**. Stage-4 semantic references and later roadmap features are not documented here as available features.

## Start here

- [`getting-started/`](getting-started/) — build/run the current CLI and compile a source file.
- [`language/`](language/) — currently implemented language concepts and units/spatial values.
- [`modeling/`](modeling/) — current Safe CAD modeling operations and known Stage-3 limitations.
- [`cli/`](cli/) — `cad build` command and machine-readable output.
- [`examples/`](examples/) — where to find repository examples/fixtures.
- [`troubleshooting/`](troubleshooting/) — diagnostics and common current limitations.

For compiler/kernel internals, use `docs/developer/`. For historical task reports, architecture audits, and stage gates, use `project/`.
