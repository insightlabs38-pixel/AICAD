# Examples

Repository examples and acceptance fixtures live primarily under the top-level `examples/`, `tests/fixtures/`, and stage benchmark directories.

When using an example, check its owning README/task context: some repository files are acceptance or future-stage benchmark inputs rather than a promise that every referenced future capability is currently implemented.

For a first user workflow, prefer examples that exercise the Stage-3 Safe CAD functions listed in `../modeling/` and build them through `cad build`.
