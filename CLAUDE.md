# Claude Code-specific instructions

## Git policy

All commits made in this repository must use:

- Author: `insightlabs38-pixel <insightlabs38@gmail.com>`
- Committer: `insightlabs38-pixel <insightlabs38@gmail.com>`

Never add AI/Claude attribution to commits or pull requests.

Specifically, never add:

- `Co-Authored-By: Claude ...`
- any `noreply@anthropic.com` co-author
- `Generated with Claude Code`
- `Generated by Claude Code`
- `Claude-Session:`
- Claude Code session URLs
- any equivalent statement identifying a commit or PR as Claude-generated

Do not bypass, disable, edit, replace, or work around `.githooks`,
`core.hooksPath`, or the repository Git identity policy.

If a Git hook rejects a commit, correct the commit message or Git identity
and retry normally. Do not use `--no-verify` or change `core.hooksPath`
to bypass the policy.
